# Data of Average Monthly Temperature of Bangladesh Divisional Cities

A dataset containing temperature of Dhaka, Sylhet, and Chittagong
Cities.

## Usage

``` r
bdtemp
```

## Format

A data frame with 36 rows and 3 variables:

- Temperature:

  Average monthly temperature

- Month:

  Month of the year

- City:

  Name of the city
