# Data of Earthquakes in and around Bangladesh

A dataset containing earthquakes magnitude, depth, and location
information.

## Usage

``` r
bdquake
```

## Format

A data frame with 13 rows and 5 variables:

- latitude:

  Latitude

- longitude:

  Longitude

- depth:

  Depth

- mag:

  Magnitude

- hms:

  Time

## Source

[USGS](https://earthquake.usgs.gov/earthquakes/search/)
