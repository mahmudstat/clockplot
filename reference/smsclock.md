# Data of Times of Receiving of SMS

A dataset containing timings of receiving sms on mobile phone. Real data
from 01 to 09 September, 2024

## Usage

``` r
smsclock
```

## Format

A data frame with 82 rows and 7 variables:

- Date:

  Date

- day:

  Day

- time:

  Time in HH:MM:SS format

- sender:

  Name of the sms sender

- invoked:

  Whether the sms is invoked by the user

- type:

  The category of the sms; offer, info, ad, service etc.

- Title:

  Message Title

## Source

Phone Messages
